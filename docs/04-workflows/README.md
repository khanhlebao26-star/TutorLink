- [WF01 Tutor approval](WF-01-tutor-approval.md): G1, Auth/Profile/Admin/File.
- [WF02 Publish and discover](WF-02-publish-and-discover.md): G1, Catalog/Listing/public UI.
- [WF03 Direct messaging](WF-03-direct-messaging.md): G2, pair/read/retry/attachment.
- [WF04 Program invitation](WF-04-program-invitation.md): G2, Draft/snapshot/accept.
- [WF05 Workspace completion](WF-05-workspace-and-completion.md): G3, sáu tab/lifecycle.
- [WF06 Review and report](WF-06-review-and-report.md): G3–G4, trust/evidence/audit.

Nhánh lỗi không phải optional. Xem [test scenarios](../06-acceptance/test-scenarios.md) và ghi evidence theo từng AC, không chỉ screenshot trang chính.
