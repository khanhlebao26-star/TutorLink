# Project glossary

- A/B/C: dòng phân công Khanh/Dũng/Hoàng, không permission hoặc branch hiện tại.
- W1-A3: mã work package; không GitHub issue number. Mapping #14/#15/#16 trong backlog cần kiểm issue live trước external write.
- G1/G2/G3/G4: Marketplace/Connection+Program/Workspace/Release gates.
- PRD: behavior/scope/AC cho module, không test report.
- ADR: decision có context/hệ quả; Proposed không nghĩa đã approved.
- BR/FR/AC: rule/requirement/acceptance scenario stable ID trong docs mới.
- Implemented: có code; Verified: có test evidence; Accepted: reviewer/người nghiệm thu đồng ý.
- API mode: gọi backend thật; mock mode: preview không chứng minh integration.
- Baseline: commit + dirty diff + thời điểm; không chỉ branch name.
- Evidence: kết quả actual có môi trường/command/fixture; không checklist dự định.

Thuật ngữ sản phẩm xem [domain terminology](../02-domain/terminology.md).
