## 1. Kết quả và phạm vi

Đã triển khai `PATCH /api/v1/conversations/{conversation}/read`. Endpoint chỉ cập nhật read marker của member từ session, trong transaction; cursor chỉ tiến theo tuple `(created_at,id)` của message, không so sánh riêng ID hoặc thời điểm gọi API.

- Kiểm membership trước validation để outsider/Admin nhận 404 kể cả payload sai; không lộ sự tồn tại của Conversation qua lỗi validation.
- Khóa và đọc lại User actor, kiểm active/role; sau đó khóa Conversation thuộc scope, pivot của actor và đọc message đích/mốc hiện tại dưới shared lock. Transaction có tối đa 3 lần thử theo cơ chế retry của Laravel.
- Message đích phải tồn tại trong đúng Conversation và có created_at. Timestamp được đọc qua Query Builder và so sánh bằng CarbonImmutable, giữ phần thập phân; ID là tie-breaker khi timestamp bằng nhau.
- Chỉ ghi `last_read_message_id` và `last_read_at` của actor khi đích xa hơn. Mốc cũ/bằng trả 200 với marker hiệu lực; không refresh last_read_at.
- Không nhận null/reset, member/user ID hoặc thời điểm đọc do client tự chọn. Không reopen chat, ghi message, FileLink, notification/outbox hoặc broadcast.
- Member active vẫn đánh dấu đọc được khi chat cancelled hoặc peer suspended. Actor suspended bị chặn, gồm trường hợp User object được lấy trước lúc suspend và phải chờ khóa.

## 2. API và schema delta

| Method/path | Request | Response thành công |
|---|---|---|
| PATCH /api/v1/conversations/{conversation}/read | JSON `last_read_message_id` bắt buộc, integer dương; không nhận field khác | 200, data gồm conversation_id, last_read_message_id, last_read_at |

Ví dụ request:

```json
{"last_read_message_id": 900}
```

ID gửi dưới dạng JSON number; chuỗi `"900"`, float, boolean, null hoặc thiếu field đều bị từ chối. Response trả cursor thực tế sau cập nhật/no-op; không bảo đảm ID trả về luôn bằng ID client gửi. `last_read_at` là UTC RFC 3339 hoặc null nếu giữ nguyên marker legacy có thời điểm null. Thành công có `Cache-Control: private, no-store`; session cookie/CSRF và X-Request-ID theo contract SPA.

| HTTP/code | Ý nghĩa |
|---|---|
| 401 unauthenticated | Chưa xác thực |
| 403 account_inactive | Actor không còn active |
| 404 conversation_not_found | Không thuộc membership/role được phép hoặc chat không tồn tại |
| 422 validation_failed | Payload sai, reset null hoặc field ngoài allow-list |
| 422 read_target_invalid | Message không tồn tại, thuộc chat khác hoặc không có timestamp; dùng cùng thông báo trung tính |
| 409 read_cursor_inconsistent | Marker cũ trỏ message sai chat/không hợp lệ; giữ dữ liệu và yêu cầu review |

**Không có schema delta hoặc migration mới.** Tái sử dụng conversation_members.last_read_message_id/last_read_at và index message `(conversation_id,created_at,id)`. Timestamp message vẫn precision 6 từ K03.5; last_read_at giữ precision giây theo schema hiện hành, không dùng làm thứ tự cursor. Không chạy migration hoặc data write lên database dev trong lượt bàn giao này.

### Bảy race test

Các test dùng PostgreSQL **READ COMMITTED**, process/kết nối độc lập. Parent giữ khóa, worker báo PID; kiểm pg_blocking_pids có blocker trước khi nhả khóa.

1. Hai read cạnh tranh giữ timestamp xa nhất dù message mới có ID nhỏ hơn.
2. Timestamp bằng nhau giữ message ID lớn hơn.
3. Hai mốc cũ không làm lùi marker đã xa hơn hoặc đổi last_read_at.
4. Hai participant chỉ cập nhật marker của chính mình.
5. H02 suspend commit trước read đang chờ: actor cũ bị 403, marker không đổi.
6. Read commit trước H02 suspend: marker giữ lại, request tiếp theo bị 403.
7. Send chờ read commit: tin đến sau target vẫn unread, không bị đánh dấu đã đọc quá mốc.

Race gọi action trong worker; hành vi HTTP được kiểm riêng bằng API tests. Không coi đây là browser end-to-end. Docker orphan-container warning thuộc Compose khi cùng tồn tại service dev/test; không phải test warning của Pest. Không dùng --remove-orphans hoặc xóa service dev để che thông báo.

## 5. Known limitations và blocker

- Chưa ghi nhận blocker kỹ thuật trong phạm vi read cursor; Hoàng chưa review, K03.6 chưa commit/PR hoặc triển khai staging/production trong lượt này.
- Chưa chạy toàn bộ backend suite, browser CSRF/session, frontend hoặc benchmark. Nhóm 107 test chỉ xác nhận các phần liên quan đã nêu.
- Marker legacy sai trả 409 và không tự sửa/backfill. Không bổ sung composite FK để xử lý mọi writer ngoài endpoint; dữ liệu cũ cần audit/phương án sửa riêng.
- Đảm bảo đơn điệu áp dụng cho endpoint này và các writer tuân thủ lock/immutability hiện hành. Không chứng nhận script sửa trực tiếp database hoặc future writer xóa/sửa message; K03.8 phải bảo toàn lịch sử.
- Khóa User/Conversation serialize các thao tác có chung tài nguyên; chưa chứng nhận NFR throughput. last_read_at chỉ có precision giây, không được dùng để sắp xếp hoặc resync message.
- Chưa có read receipt realtime; scanner, attachment và broadcasting thuộc K03.7–K03.8/K03.11–K03.13. Fixture clean là metadata kiểm thử, không phải evidence antivirus scan.
- Redocly còn 45 warnings cũ. Toàn BE-K03 chưa hoàn tất.
