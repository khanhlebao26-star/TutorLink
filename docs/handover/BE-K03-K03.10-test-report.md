## 4. Chi tiết race File

Ba test method bao phủ bốn lượt cạnh tranh:

| Thứ tự | Kết quả | Trạng thái cuối |
|---|---|---|
| Tạo VerificationDocument trước, delete chờ khóa | Attach 201; delete 409 | File/document và bytes object giữ nguyên |
| Delete trước, attach chờ khóa | Delete 204; attach 404 | Không còn File/object, không có document hoặc FileLink mồ côi |
| Generic link trước, delete chờ khóa | Link 200; delete 409 | Document/File/Link/object được giữ |
| Delete kiểm tra trước generic link trên file đã có document | Delete 409; link sau 200 | File không thể bị xóa dù FileLink đang được tạo |

Ở ca delete thắng, request attach đã qua validation khi deletion còn chưa commit, sau đó chờ khóa File thật. Sau commit, SELECT FOR UPDATE không còn thấy row nên trả 404; không nới assertion thành mọi lỗi 4xx hoặc 500.

Process cha gọi HTTP test API; process con đi qua HTTP Kernel với authenticated test guard. Cả hai dùng cùng storage root riêng, test so sánh bytes/checksum và dọn đúng thư mục được tạo. pg_blocking_pids xác nhận worker khác session đang bị transaction cha chặn trước khi giải phóng; usleep chỉ giảm tần suất polling điều kiện này. Đây không phải kiểm thử login/cookie/CSRF qua trình duyệt hoặc kiểm thử tải thực tế nhiều người dùng.

Phạm vi generic link hiện chỉ verification_document. Việc tạo VerificationDocument.file_id là một tham chiếu nghiệp vụ độc lập với FileLink và cũng chặn delete. Không suy kết quả này thành generic link-vs-delete cho Task/Submission/CV/message chưa được hỗ trợ.

## 6. Known limitations và việc tiếp theo

- Không có antivirus tự động. clean/complete chỉ phản ánh kiểm tra kỹ thuật, không chứng nhận file không có malware. Không tạo engine/version/scanned_at giả.
- Chưa có chat UI để nghiệm thu E2E. Reverb/Echo, reconnect và thu hồi quyền socket đang mở thuộc K03.11–K03.13, chưa được chứng nhận bởi REST tests.
- Conversation expiry hiện lazy; chưa có worker tự đóng chat ngay thời điểm Invitation hết hạn. Reject/cancel Invitation riêng và các writer tương lai cần tích hợp lifecycle/test riêng.
- Task/Submission resource policy/versioning, CV approval theo version và download tương ứng thuộc module phụ trách; generic File enum/purpose không có nghĩa endpoint nghiệp vụ đã triển khai.
- Orphan cleanup/storage compensation và tình huống rollback/commit lỗi giữa storage với database chưa được chứng nhận. Race hiện tại chỉ xác nhận các thứ tự thành công/từ chối của luồng VerificationDocument đang có.
- Các test này không phải benchmark throughput/latency hoặc toàn bộ kiểm thử non-functional. Các khoảng trống target/runtime của module khác không tự hoàn tất khi full suite pass.

Không có blocker kỹ thuật trong phạm vi backend lõi đã kiểm; **chờ Hoàng review**. Tiếp theo: K03.11 backend broadcasting/Reverb. Người dùng tự commit/push/cập nhật issue/yêu cầu review; chưa đánh dấu toàn BE-K03 hoàn tất.
