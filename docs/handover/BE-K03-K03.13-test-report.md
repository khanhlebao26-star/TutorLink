## 3. Quyền, transaction và race

- Registry ràng buộc token với HMAC session ID và User; cấp channel và auth kiểm session database còn hiệu lực, account/role, Profile không suspended, membership và trạng thái chat cho phép đọc.
- Logout chỉ thu hồi phiên hiện tại. Suspend account/Profile thu hồi mọi phiên trong transaction nghiệp vụ; restore không bỏ dấu revoked. Đổi mật khẩu có rotation session ID thu hồi grant cũ; regression Identity chạy cùng nhóm test.
- Request cũ ghi lại HTTP session sau logout vẫn bị tombstone chặn; rollback suspend giữ quyền/session và trạng thái account.
- Event nội bộ `ConversationMessagesChanged` chỉ dispatch sau outer commit. Listener rescue lỗi enqueue; custom job chỉ mang Conversation ID, kiểm quyền hiện tại trước transport.
- Publisher giữ khóa User theo ID tăng dần trong lúc kiểm và phát. `RealtimeRevocationConcurrencyTest` dùng hai process/kết nối PostgreSQL độc lập, chờ bằng `pg_blocking_pids`: revoke commit trước thì không publish; publish giữ khóa thì revoke phải đợi, sau revoke job khác không publish.
- Replay/conflict/validation/quota/outsider/outer rollback không thêm notification; lỗi enqueue hoặc transport không làm mất message đã commit.

Race test dùng broadcaster giả để quan sát khóa, không giả làm evidence nhận socket thật. Probe HTTP/WebSocket là bằng chứng tích hợp riêng. Không chạy test race bằng SQLite hoặc `--parallel`.

## 4. API/schema và contract delta

- Thêm **POST `/api/v1/conversations/{conversation}/realtime`**: body rỗng, browser session + CSRF; 200 trả `channel`, `event`, `expires_at`, private/no-store. Không trả HTTP session ID/hash/secret. Có 401/403/404/422 theo bước kiểm tra; CSRF middleware có thể trả 419.
- Channel mới: `private-conversations.{id}.sessions.{64-hex-token}`. API cấp channel trả tên không có `private-`; legacy shared channel bị từ chối, không dual-publish.
- Lease theo `session.lifetime`, runtime hiện 120 phút. Cấp lại khi chưa hết hạn dùng token cũ và gia hạn; hết hạn rotate; revoked không được gia hạn. Frontend sau này phải gia hạn trước expiry.
- **POST `/broadcasting/auth`** vẫn là route web ngoài `/api/v1`, không tự cộng vào OpenAPI. Thêm route cấp channel làm tổng artifact từ 69 lên **70 operations**.
- Migration mới: `2026_10_30_180000_create_realtime_sessions_table`; unique User/session hash, unique token, expiry/revoked index. Không thay bảng Message/File, không xóa scan evidence lịch sử.
- Database sessions và registry cùng application connection. Runtime: PHP 8.3.36, Laravel 13.35.0, Reverb 1.12.0, database queue, broadcaster reverb, client events none; transport connect timeout 2 s/timeout 5 s.
- Đã cập nhật K03.1, Catalog, API README, roadmap và ghi bổ sung vào BR-17/BR-21, lifecycle, M04 PRD, WF03, kiến trúc và schema reference. Sơ đồ draw.io chưa cập nhật.

## 6. Cleanup, giới hạn và việc tiếp theo

- Mọi service bị dừng đã khôi phục. Probe chỉ xóa fixture được đối chiếu tag/email/ID: User, Conversation/message/member, document/File/profile, audit/notification/outbox, session/registry và job thuộc Conversation đó. JSON cuối ghi số còn lại bằng 0 cho các tài nguyên được kiểm theo fixture User/Conversation ID; anonymous HTTP session không mang User ID theo TTL thông thường. Không xóa volume, image, queue hoặc dữ liệu người dùng khác.
- Report/log không lưu password, session cookie, HMAC authorization hoặc token channel. Source/evidence fingerprint không đọc `.env`/secret.
- Notification best effort, có thể mất/lặp; chưa có realtime outbox, TLS deployment, load/soak hoặc fault-injection nhiều node. Không chứng nhận giao đúng một lần.
- TCP socket cũ có thể còn mở. Notification đã publish trước revoke có thể đến muộn; khóa chỉ bảo đảm không publish mới theo quyền cũ sau revoke commit.
- Tombstone chưa có cleanup tự động; session database khác connection/driver chưa được hỗ trợ. File Task/Submission/CV và cleanup/storage compensation không được chứng nhận bởi task realtime này.
- **K03.12 Echo/UI tiếp tục hoãn**: chưa kiểm UI không nhân đôi, listener/subscription cleanup hoặc polling fallback trong Next.js. Consumer probe không thay thế các tiêu chí đó.
- Tiếp theo: K03.14 bàn giao backend, người dùng tự commit/push/cập nhật issue và gửi Hoàng review; giữ frontend backlog, không đánh dấu hoàn tất UI hoặc toàn phạm vi realtime ban đầu.
