## 1. Chuẩn bị

- Docker Desktop Linux engine/Compose đang chạy, Git và Node.js 24+ cho probe. Docker cung cấp PHP/Composer, không cần PHP host.
- Checkout đúng branch/commit khi working tree đã được bảo toàn theo quy trình của reviewer; kiểm `git status --short` và `git log -1 --oneline`.
- Cần các cổng local 8000 (REST), 8080 (Reverb), DB theo Compose. Chưa cần chạy frontend/Echo để test backend.
- Tạo environment từ example chỉ khi file chưa có:

```bat
if not exist backend\.env.docker copy backend\.env.docker.example backend\.env.docker
```

Backend mount environment read-only trong container. Điền giá trị ở file host; không ghi/publish secret vào docs/PR/evidence. Giữ APP_KEY của môi trường đã có. Với môi trường local mới có APP_KEY trống, sau build có thể dùng `docker compose run --rm --no-deps backend php artisan key:generate --show --no-interaction`, rồi chép kết quả vào APP_KEY ở file host; không dùng key:generate ghi trực tiếp file read-only.

## 2. Environment cần có

DB hostname trong mạng Docker là `db`. Docker Compose đã khai báo environment DB cho backend; kiểm cấu hình phù hợp với môi trường local. Không đổi tên/user/database test trong compose.testing.yml sang dev.

```dotenv
APP_ENV=local
APP_URL=http://localhost:8000
FRONTEND_URL=http://localhost:3000
SESSION_DRIVER=database
SESSION_LIFETIME=120
QUEUE_CONNECTION=database
BROADCAST_CONNECTION=reverb
REVERB_APP_ID=tutorlink-local
REVERB_APP_KEY=tutorlink-local-key
REVERB_APP_SECRET=<set-a-local-random-secret>
REVERB_HOST=reverb
REVERB_PORT=8080
REVERB_SCHEME=http
```

Placeholder secret phải được thay ở môi trường local. Backend và Reverb/worker dùng cùng credentials; secret không cấp cho client. SESSION_CONNECTION bỏ trống để dùng default DB hoặc phải cùng application connection. Registry không hỗ trợ session driver/connection tách biệt. Reverb được service command bind 0.0.0.0:8080; origin cho phép localhost/127.0.0.1, client events none. Local HTTP không chứng nhận production HTTPS/WSS.

Không cấu hình CLAMAV_* hoặc chạy service scanner. Giữ scan evidence schema/lịch sử; clean chỉ kiểm kỹ thuật. compose.testing.yml giữ BROADCAST_CONNECTION=null cho regression thường; test broadcast chuyên biệt tự cấu hình phần cần kiểm.

## 3. Build, dependency và migration

```bat
docker compose config --quiet
docker compose build backend
docker compose up -d db backend
docker compose exec -T backend composer install --no-interaction --prefer-dist
docker compose exec -T backend php artisan migrate:status --no-ansi
docker compose exec -T backend php artisan migrate --no-interaction
docker compose exec -T backend php artisan config:clear
docker compose up -d --build reverb broadcast-worker
```

Docker image đã có vendor theo lock; composer install xác nhận named vendor volume khớp lock trên máy reviewer. Khi cập nhật code/dependency, cần restart worker để nạp class mới. Nếu sửa environment của các service đang tồn tại, `docker compose up -d backend reverb broadcast-worker` sẽ reconcile cấu hình; config:clear rồi restart worker/Reverb nếu cần.

Migration align Messaging có guard: nếu dữ liệu cũ có type/status legacy hoặc messages cần canonical payload backfill, dừng để lập mapping/backup theo owner DB. Không sửa migration đã chạy, migrate:fresh hoặc xóa dữ liệu để vượt guard. Không dùng down -v hay --remove-orphans. Không clear queue toàn dự án; payload job K03.11 cũ cần đối soát riêng khi nâng phiên bản, không dùng làm demo K03.13.

Không lưu cookie, auth HMAC hoặc token channel vào evidence. Logout/suspend không yêu cầu TCP cũ đóng; kiểm không có notification publish mới theo quyền cũ.

## 5. Chạy test khi cần xác nhận lại

Test image COPY source nên dùng --build sau khi source thay đổi. Test chạy PostgreSQL riêng, không đụng database dev; không --parallel cho race đang chia sẻ DB.

```bat
docker compose -f compose.testing.yml run --rm --build -T backend-test php artisan test --compact --filter="ConversationBroadcastAuthTest|RealtimeSessionAccessTest|MessageBroadcastTest|RealtimeRevocationConcurrencyTest|IdentitySessionTest|SendTextMessageApiTest|SendTextMessageConcurrencyTest" --display-warnings --fail-on-warning --no-ansi
```

Sau targeted pass, nếu cần chạy toàn backend trên cùng image chưa đổi source:

```bat
docker compose -f compose.testing.yml run --rm -T backend-test php artisan test --compact --display-warnings --fail-on-warning --no-ansi
```
