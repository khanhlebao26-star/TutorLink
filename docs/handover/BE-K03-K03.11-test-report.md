## 3. Backend và regression

SendTextMessage phát ConversationMessagesChanged chỉ ở nhánh insert mới. Event dùng ShouldDispatchAfterCommit, ShouldBroadcast, ShouldRescue; worker database xử lý queue broadcasts. broadcastWith() chỉ trả conversation_id, không serialize Message/body. Replay trả trước dispatch. Lỗi enqueue được report, không phá response sau commit; lỗi transport ở worker không rollback message.

Channel kiểm User active/chưa xóa/role hợp lệ và membership hiện tại trong DB. Member active được subscribe chat cancelled hoặc peer suspended theo quyền đọc lịch sử. POST /broadcasting/auth là route web dùng session, CSRF, EnsureActiveApiActor và request validation. Reverb tắt client events, giới hạn origins local. Secret không đưa vào frontend.

## 4. API/schema và dependency delta

- Thêm **POST /broadcasting/auth**, nhận socket_id/channel_name; trả auth signature khi được phép. Chưa xác thực 401; actor/membership không hợp lệ 403; payload sai 422; thiếu/sai CSRF 419. Lỗi validation/CSRF dùng envelope Laravel của route web, không hứa giống envelope Messaging.
- Route ngoài /api/v1 nên không nằm trong Scramble artifact. Export/parity thật xác nhận **69 operations**, không cộng thành 70. Catalog ghi route đã đăng ký ngoài OpenAPI, kèm policy/evidence.
- Thêm private channel conversations.{id}, event conversation.messages_changed với data {conversation_id}; frontend resync bằng REST after cursor. Không đổi DTO message hoặc mở luồng ghi WebSocket.
- Không thêm migration/bảng. Dùng lại jobs/failed_jobs; thêm service reverb và broadcast-worker chung code/vendor/storage/config với backend. Backend → Reverb dùng reverb:8080 trong Docker; client local dùng localhost:8080.
- Runtime: Laravel **13.35.0**, Reverb **1.12.0**, Pusher PHP **7.3.0**, Guzzle **7.16.1**, PSR-7 **2.13.2**, Symfony MIME **7.4.22**. Full suite kiểm source/dependencies sau cài Reverb; audit không còn advisory.

## 5. Known limitations và việc tiếp theo

- Chưa có UI chat/Echo nghiệm thu. Probe là HTTP client + ws, không phải browser/Echo hoặc UX K03.12. Có kiểm CORS/preflight thật, chưa phải toàn bộ kiểm thử trình duyệt.
- Auth kiểm quyền tại subscribe. **Chưa xử lý thu hồi quyền socket đã subscribe khi suspend/logout**; thuộc K03.13. Không tuyên bố kết nối cũ đã bị ngắt khi mất quyền.
- Outage thật chỉ thử worker. Reverb shutdown, queue backend mất kết nối thật và failed-job retry vận hành cần evidence riêng; unit test đã mô phỏng enqueue/transport failure.
- Broadcast best effort: crash sau commit trước enqueue hoặc enqueue thất bại có thể mất notification. Chưa có realtime transactional outbox. REST/polling/resync phục hồi dữ liệu; worker retry có thể giao event lại, không bảo đảm exactly-once.
- Không dùng conversation_id trong event làm cursor/bằng chứng đọc. Client dedupe server message ID và lấy cursor từ API ở K03.12.
- Local HTTP/ws, một Reverb và database queue; chưa có TLS/wss, reverse proxy, nhiều instance hoặc load benchmark production.
- Giữ text-only, File policy và lazy Conversation expiry theo K03.1/K03.9/K03.10.

Tiếp theo: **K03.12 — Frontend Echo và resync**, rồi K03.13 thu hồi quyền/nghiệm thu realtime. Chờ Hoàng review; không đánh dấu toàn BE-K03 hoàn tất.
