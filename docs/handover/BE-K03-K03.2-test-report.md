## Thay đổi

- Tạo model Conversation và Message.
- Bổ sung User::conversations().
- Khai báo các quan hệ membership, message, sender, Listing context và attachment.
- Attachment giới hạn theo file_links.resource_type=message.
- Thêm migration 2026_10_28_034616_align_messaging_contract.
- Thay index message hai cột bằng (conversation_id, created_at, id).
- Giữ unique direct_key và unique (sender_id, client_message_id).
- Bổ sung payload_hash CHAR(64), nullable.
- Đổi default Conversation status thành active.
- PostgreSQL chỉ nhận Conversation type=direct và status active/cancelled.
- Migration dừng nếu gặp Conversation legacy hoặc message cần backfill.

## Kiểm tra dữ liệu trước migration

Database Docker local chưa có Conversation, conversation member, message hoặc file link loại message tại thời điểm kiểm tra.

Không có dữ liệu pending/expired/type=program cần chuyển đổi ở môi trường local này.

## Kiểm tra sau migration

Các output SQL đã xác nhận:

- Default type=direct, status=active.
- Index (conversation_id, created_at, id) tồn tại; index cũ hai cột đã được thay thế.
- Hai unique constraint của Messaging vẫn tồn tại.
- payload_hash là CHAR(64), nullable.
- Constraint status/type/direct_key phù hợp với schema đích.

## Known limitations

- Migration hiện không tự chuyển đổi dữ liệu chat legacy; môi trường có dữ liệu cần mapping/backfill riêng.
- Các test nghiệm thu mới yêu cầu PostgreSQL; không coi kết quả skip trên SQLite là đã kiểm chứng constraint PostgreSQL.
- Attachment fixture chỉ kiểm liên kết database, không chứng minh upload, quyền download hoặc antivirus scan.
- payload_hash mới là phần chuẩn bị schema; tính hash và xử lý replay thuộc K03.5.
- API, concurrency nghiệp vụ, File scanner và realtime được nghiệm thu ở các task tiếp theo.
